ESP32 하드웨어 배선 가이드 (Pinout Table)

모듈 / 부품명 ESP32 GPIO 핀 전원 / 통신 방식 설명
OLED Display SDA: 21, SCL: 22 3.3V / I2C (0x3C) 0.96인치 128x64 SSD1306 화면 출력
서보모터 (SG90) PWM: GPIO 18 5V / PWM Signal 사료 디스펜서 밸브 개폐 (0° ↔ 90°)
수동 부저 (Buzzer) PWM: GPIO 19 3.3V ~ 5V / PWM 급식 시 3가지 알림 멜로디 출력
PIR 감지 센서 IN: GPIO 27 3.3V ~ 5V / Digital IN 급식구 앞 5분 감지(식사 중) / 1시간 무반응(미섭취)
[신규] 초음파 센서 (HC-SR04) TRIG: 5, ECHO: 4 5V / Digital I/O 뚜껑 안쪽 하향 설치 (20% 이하 시 사료 부족 알림)

Blynk IoT Cloud Datastream 정의표

가상 핀 데이터스트림 이름 데이터 타입 설명
V1 Feed Counter Display String 카운터 표시 (예: "2/3")
V2 Manual Feed Button Integer (0/1) 수동 급식 원격 버튼
V3, V7~V9 Schedules #1~#4 Time Input 1차~4차 급식 시간 개별 지정
V10 Meal Status String 식사 상태 ("EATING", "SKIPPED", "WATCHING")
V11 PIR Motion Indicator Integer (0/1) PIR 실시간 움직임 LED 표시
V12 Food Level Percent Integer (0~100) 초음파 센서 사료 잔량 퍼센트
V13 Food Low Warning String 20% 이하 사료 채움 경고 알림
