모듈 / 부품명 ESP32 GPIO 핀 전원 / 통신 방식 설명
OLED Display SDA: 21, SCL: 22 3.3V / I2C (0x3C) 0.96인치 128x64 SSD1306 간결 화면 출력
서보모터 (SG90) PWM: GPIO 18 5V / PWM Signal 사료 디스펜서 밸브 개폐 (0° ↔ 90°)

적외선(IR) 감지 센서 IN: GPIO 27 5V (VIN) / Digital IN 반려동물 감지 시 5분(300초) 실시간 초 카운팅
초음파 센서 (HC-SR04) TRIG: 5, ECHO: 4 5V / Digital I/O 뚜껑 안쪽 하향 설치 (20% 이하 시 사료 부족 알림)
